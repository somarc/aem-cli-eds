Authentication

Explicit token lifecycle for DA and Helix Admin operations.

The fork exposes auth as a first-class top-level workflow while reusing the existing project-local token storage pattern.

Commands

aem auth login
aem auth status
aem auth token
aem auth logout

Storage

Tokens are cached in the project under .hlx/.da-token.json and are ignored from Git by the helper path already used by the content workspace.

Automation can provide --token to avoid browser login.
