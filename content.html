Content

The existing content workspace remains the collaboration model for DA source edits.

This part of AEM CLI was already aligned with DA, so the port leaves it intact.

Clone

Pull DA content into a local content/ workspace.

aem content clone --path /

Stage and commit

Use Git-like commands inside the content workspace.

aem content status
aem content add
aem content commit -m "Update"

Push

Push committed content changes back to DA with conflict checks.

aem content push --dry-run
aem content push
