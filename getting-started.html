Start

Install once. Develop locally. Operate the delivery pipeline from the same CLI.

This fork is designed for teams already using Adobe's AEM CLI and ready to add DA Admin and Helix Admin operations to their normal workflow.

Recommended setup

Local development

$ npm install -g @adobe/aem-cli
$ aem up

Keep using the official local development server for browser preview, proxying, live reload, TLS, and local content rendering.

DA operations

$ aem auth login
$ aem preview page /index
$ aem publish page /index --commit

Use the new modules when the work moves from local development into remote delivery operations.

Project inference

The new commands infer owner, repo, and branch from the current Git checkout. Automation can still pass --owner, --repo, --branch, and --token explicitly.
