Index and code

Inspect query-index health and code-bus state without leaving the CLI.

These read-first commands help distinguish content problems from index or code delivery problems.

Index

aem index show
aem index validate --env preview
aem index query blog --filter type=article

Uses the official shared config parser for helix-query.yaml.

Code

aem code status /scripts/scripts.js
aem code sync /styles/styles.css --commit
aem code sidekick get

Sync is commit-gated. Status, job lookup, and sidekick read are safe inspection paths.
