Delivery

Preview is fast. Publish is explicit.

The port keeps preview convenient and makes live mutations deliberate with --commit.

Flow

1. Flush DA preview

aem preview starts by clearing the DA editor preview cache when possible.

2. Trigger Helix build

The command calls Helix Admin preview for the selected path, tree, or status target.

3. Promote live

aem publish and the publish step of aem deploy require --commit.

$ aem preview tree /docs
$ aem publish tree /docs --commit
$ aem deploy page /index --commit
