Routes

Know whether a URL is DA-owned, code-owned, hybrid, or orphaned.

Route classification is the safety layer before cleanup, migration, or publish decisions.

ClassMeaningAction
contentbusDA source or DA delivery source is present.DA preview and publish workflows apply.
codebusThe route is backed by code repository content.Use code-bus inspection before assuming DA changes matter.
hybridBoth DA and code evidence exists.Review ownership before mutation.
orphanNo source was found by probes.Check canonical path and source document extension.
aem route classify /blog/post
aem route canonical /index.html
aem route audit /docs --concurrency 10
